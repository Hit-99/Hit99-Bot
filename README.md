# Hit99-Bot
The Discord and Fluxer Bot for the Hit-99 community!

## Features: 
- Recieve match stats from all premier, comp, and wingman games
- Get premier rating (!rating)
- Auto roles on join
- Server logging
- Reaction roles
- Premier based role
- Steam account link verification

## Commands
- !link <steamID/steam URL>
- !rating
- !stats \<steamID> (WIP)
